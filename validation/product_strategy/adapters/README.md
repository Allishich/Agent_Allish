# Примечание об адаптерах

Эта папка намеренно **не содержит обязательного исполняемого кода**.

К платформам, которые могут автоматически читать `MODULE.md` и передавать JSON, модуль подключается напрямую через правила `handoff.yaml`.

К платформам с иной системой инструкций требуется адаптер, передающий текст `MODULE.md`, `EXECUTOR.md`, `workflow.yaml`, `method_routing.yaml` и нужных `methods/*.yaml` в контекст исполнителя.

Для платформ без доступа к файлам родитель может передать содержимое разрешённых YAML и самостоятельно сохранять результаты из `module_response.artifacts[].content`. Для платформ без долговременного хранилища продолжение между сессиями не гарантируется.

Если в будущем потребуется отдельный Python-валидатор или API, он может использовать `contracts.json`, не изменяя методики и декларативный протокол.
