# Журнал версий: product_strategy v0.2.0

Дата: 2026-11-21.

- Убран обязательный Python CLI и прямой локальный `AGENTS.md` как точка входа; вместо этого — `MODULE.md`.
- Продуктовая аналитика оформлена **подключаемым модулем** главного агента, без собственного начального интервью и без коммуникационной стратегии.
- `workflow.yaml` описывает 7 фиксированных этапов, выбор условных методов, статусы, контрольные точки и возобновление.
- `method_routing.yaml` — байт-в-байт исходный согласованный `seven_stage_route_v0_1.yaml`, включая 21 метод (проверяется при сборке).
- `handoff.yaml` — распределение ответственности и родительский JSON-контракт.
- `contracts.json` — JSON Schema 2020-12 внешних запросов, ответов, состояния, методических/этапных результатов и каркаса стратегии.
- `EXECUTOR.md` переписан платформенно-нейтрально, сохраняет различие нативных результатов M01–M10 и M11–M21.
- Установлено правило `saved:true` только после фактической записи, сохранение состояния может быть делегировано главному агенту.
- 21 YAML-методика скопирована из последнего утверждённого комплекта **без изменений**.
- Предыдущие Python v0.1 и инструкции Codex/Cursor не удаляются с Google Drive; остаются отдельной архивной реализацией.
- Методологическая повторная проверка не проводится; локальная техническая проверка схем и структуры — не новый методологический аудит.
