# Communication Strategy — модуль коммуникационной стратегии

**Статус:** заготовка для поэтапной разработки. Модуль пока не реализован и не подключён к главному агенту.

## Назначение

Разработать коммуникационную стратегию, согласованную с продуктовой стратегией и бизнес-целями пользователя.

## Место в Agent_Allish

- `validation/common_intake/` — общий подтверждённый бриф.
- `validation/product_strategy/` — продуктовые исследования и решения.
- `validation/communication_strategy/` — будущая коммуникационная стратегия.

Коммуникационный модуль должен использовать подтверждённые продуктовые выводы, отделять гипотезы от фактов и возвращать продуктовому модулю значимые новые наблюдения или противоречия через главного агента.

## Границы текущего шага

Эта папка создана только как рабочее пространство. Этапы, методики, контракты обмена, критерии качества и интеграция ещё подлежат обсуждению и тестированию.

Не изменять существующие `common_intake`, `product_strategy`, корневые `AGENTS.md` и `methodology.md` без отдельного согласования.

## Следующий шаг

Совместно разработать методологию коммуникационной стратегии, затем поэтапно добавить инструкции, методы, форматы обмена и тесты.
