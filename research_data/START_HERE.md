# Рыночный агент — исследовательская база в GitHub

> Это **новый каталог** `research_data/` в репозитории `Allishich/Agent_Allish`.
> Основные данные и паспорта скопированы из Google Drive. Исходные материалы на Drive не изменялись.

## Что содержится в пакете

- **43 логических набора** для анализа российских рынков: демография (9, включая вспомогательные таблицы), социально-экономические показатели (5), цифровое поведение (10), предприятия/B2B (10), потребление и условия жизни (9).
- **29 индивидуальных JSON-паспортов**, плюс общие исходные манифесты и отчёты QA для разделов без индивидуальных паспортов.
- **12 маршрутов** от исследовательского вопроса к возможным наборам данных.
- Реестр 150 файлов исходного хранилища с отметкой, какие документы действительно скопированы в этот репозиторий.
- Каталог внешних источников и документация Mediascope — **справочные материалы, не подключённые API**.

## Быстрый старт для ИИ

1. Уточни продукт/рынок, аудиторию, географию, период и требуемый показатель.
2. Прочитай `research_data/AI_CONTEXT/data_rules.md`, затем выбери релевантную запись в `research_data/AI_CONTEXT/routing.json`.
3. В `research_data/AI_CONTEXT/manifest.json` сопоставь `candidate_dataset_ids` с `indexed_datasets[].dataset_id`. Учитывай `native_dataset_id` для точного источника.
4. Сначала открывай **репозиторные пути** `data_file.repository_path` и `metadata_file.repository_path`; для разделов без индивидуального паспорта — `source_catalog.repository_path` и отчёты в `quality/`.
5. Проверяй период, единицу счёта, знаменатель процента, население/организации в охвате, географию, способ получения, статус QA и ограничения. Только затем открывай и анализируй строки CSV.
6. Если `data_file.repository_parts` содержит список, это **части одного исходного CSV**, а не независимые источники; см. ниже.
7. Фиксируй для каждого числового вывода используемый CSV, первоисточник, период, единицы, формулу и допущения. Не называй описания из JSON доказательством чисел.
8. Если данных недостаточно, обратись к `research_data/sources/internet_sources_catalog.json`, но не выдавай описанное API за действующее подключение.

## Особый случай: ВПН-2020, таблица 4

Исходный файл `ru_vpn2020_tab04_households_children_structure_by_region.csv` имеет размер **4 535 353 байта** и **9 120 записей**. Чтобы обойти ограничения передачи крупного файла, его содержимое сохранено без потери строк в восьми CSV-частях `datasets/demography/parts/`. Каждая часть имеет заголовок; это **один** логический набор `RU-VPN2020-TAB04`, а не восемь независимых наборов.

Для локальных расчётов можно объединять строки всех восьми частей, исключая повторные заголовки, либо выполнить из корня репозитория:

```bash
python research_data/tools/reconstruct_large_csv.py
```

Скрипт создаст полный исходный CSV **только после проверки SHA256**, ожидаемого размера и числа строк. Он не перезаписывает существующий файл, если тот отличается от проверенного оригинала.

## Проверка после получения PR

```bash
python research_data/tools/validate_package.py
```

Этот скрипт проверяет наличие путей, связи между реестром и маршрутами, 43 логических набора, 29 паспортов и доступные SHA256. Проверка содержимого первичных публикаций независимым аудитом в этот PR не входит.

## Ограничения и управление обновлениями

1. Основной архив первоисточников остаётся в Google Drive: https://drive.google.com/drive/folders/1Y9ejj2e_TAgy0GJlrVgUbY9Z9Ab47oIy. В реестрах сохранены исходные Drive ID и ссылки. Доступ к Google Drive **не требуется** для анализа скопированных CSV, но может потребоваться для уточнения происхождения и обновлений.
2. Некоторые CSV получены транскрипцией официальных опубликованных таблиц; наличие внутренних QA-проверок не означает независимую сверку всех оригинальных XLSX/PDF. Статус указан в паспорте.
3. Периоды, единицы и территориальные охваты различаются. Люди, домохозяйства, семейные ячейки, компании и ИП не взаимозаменяемы; вложенные регионы и пересекающиеся категории не складывать.
4. Внешние источники и Mediascope в данном пакете являются **документацией**, не действующими API-интеграциями.
5. Этот каталог добавлен отдельной веткой и PR. Остальные файлы репозитория `Agent_Allish` не должны меняться; дальнейшие обновления статистики согласовываются отдельными PR.
