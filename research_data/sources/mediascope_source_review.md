# Mediascope — аудит возможностей источника для «Рыночного агента»

**Дата проверки:** 17 ноября 2026 г.  
**Статус:** обзор официальных возможностей и доступности. Это **не** выгрузка данных Mediascope.  
**Сфера:** все российские B2C-рынки, цифровые и традиционные каналы; детские исследования — частный случай, а не приоритет.

## Ключевой вывод

Mediascope целесообразно сделать одним из основных источников для **потребительских категорий, аудитории конкретных сайтов/приложений, медиаканалов, брендов и поискового интереса**. Эти данные дополняют Росстат/ВШЭ и пригодны для сегментации, анализа альтернатив, TAM/SAM (при совместимых определениях) и анализа драйверов. Для полного рынка тарифных и платёжных метрик отдельные данные нужны извне.

| Продукт | Содержание | Доступность | Приоритет |
| --- | --- | --- | --- |
| BrandPulse | Категории покупок, предпочтения, частота, бренд-метрики, профиль потребителя | Полная база по лицензии; отдельные презентации публичны | 1 |
| Cross Web | Месячный/суточный охват ресурсов и приложений, длительность, профиль аудитории | Публичные рейтинги/дашборд выборочно; подробные запросы по лицензии | 1 |
| Share of Search | Поиск товаров/брендов на разных e-com площадках | Избранные открытые публикации; подробная база по подписке | 2 |
| TV Index / Radio Index / NRS | ТВ, радио, аудитория прессы | Публичные рейтинги + лицензируемые глубинные данные | 2–3 |
| Рекламный мониторинг | Конкурентная рекламная активность | По лицензии; отдельные публикации | 3 |
| Открытые доклады | Исторические срезы отраслей, e-commerce, цифровые привычки и бренды | Читаются бесплатно, но условия воспроизведения ограничены | 1 |

## Бесплатный API — проверенный статус

- **Есть** официальный Delivery API Cross Web; компания опубликовала Python-библиотеку и Jupyter-примеры.
- Для авторизации нужны `username`, `passw`, `client_id`, `client_secret`, адреса аутентификации и API; официальный README предписывает получать их у представителей компании.
- **Не подтверждены** свободный анонимный API, бесплатный ключ, бесплатная квота/тариф API и разрешение на массовую загрузку данных публичных дашбордов.
- Старый публичный дашборд `webindex.mediascope.net` указан в официальном разделе; при проверке веб-инструментом ответил HTTP 502. Это не доказывает, что он постоянно недоступен, и не свидетельствует о наличии API.

## Юридические ограничения

Официальная страница «Интеллектуальные права» требует письменного разрешения на воспроизведение материалов. «Ответственность» запрещает коммерческое распространение, изменение и передачу третьим лицам без письменного разрешения. Для интернет-публикаций нужна активная ссылка на источник. Поэтому **не копировать массово или публично переиздавать наборы данных Mediascope до выяснения условий**. Безопасный промежуточный актив — реестр доступных источников, свойств, метрик и ссылок без воспроизведения защищённых материалов.

## Последовательность подключения

1. Привязать Mediascope как источник в каталог знаний, не создавая фиктивных числовых датасетов.
2. Подготовить индекс открытых рейтингов, публикаций и презентаций по категориям и периоду с точными ссылками на оригинал и описанием охвата.
3. Проверить форму публичного интерфейса и его разрешённые способы экспорта (не считать интерфейс API).
4. Выяснить у поставщика возможность тестового/бесплатного API и лицензию для локального агента, включая хранение и переработку данных.
5. Только при подтверждённом праве доступа — подключить клиентские API и строить количественные датасеты.
