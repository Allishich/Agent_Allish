# Каталог источников для Рыночного агента — v0.1

Состояние на 2026-11-17. Исследовательский каталог, **не набор работающих коннекторов**.

## Назначение
Используется, чтобы агент выбирал 1–3 релевантных сайта для вопроса продуктового менеджера, определял допустимые способы получения данных и фиксировал ограничения. При недостаточности источников разрешён поиск новых.

## Основные правила
1. Сначала исследовательский вопрос, измерение, период, география и знаменатель; только потом выбор источника.
2. Проверять каждое значение по первоисточнику или паспорту ранее собранного датасета.
3. «Есть API» не означает «API доступен агенту»; фиксировать проверку endpoint, права и стоимость отдельно.
4. Не обходить авторизацию, капчи, антибот-защиту, лицензионные ограничения. Секреты не передавать в LLM, Drive, GitHub.
5. Не смешивать факты, прогнозы, поисковый интерес, отзывы, закупки и оценки агентств.
6. После ошибки обращаться к запасному публичному источнику или просить разрешённую выгрузку.
